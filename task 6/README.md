# Задание 6: Автоматизация обновления индекса

## Источник данных

В качестве источника выбрана локальная папка `knowledge_base/`.
Подхват новых данных: скрипт сканирует `*.md`, считает SHA-256 и сравнивает с прошлым снимком состояния.

## Скрипт обновления

`task 6/update_index.py` выполняет:
- поиск новых/изменённых/удалённых документов;
- чанкинг документов;
- генерацию эмбеддингов (модель `BAAI/bge-small-en-v1.5`);
- обновление индекса (`task 3/artifacts/faiss.index`) и метаданных;
- логирование и сохранение состояния источника.

## Периодический запуск

Пример cron: `task 6/cron.example`

План: каждый день в 06:00.
При ошибке: traceback пишется в `task 6/logs/update_index.log` и JSON-лог `task 6/logs/update_index.jsonl`.

## Логирование

Сохраняются:
- время запуска и завершения;
- число новых/изменённых/удалённых файлов;
- число новых чанков;
- итоговый размер индекса;
- ошибки.
